Project Overview

This project implements and compares Decision Tree and Random Forest algorithms for classification and regression. It includes data preprocessing, model training, evaluation, and interactive predictions using machine learning.

Decision Tree

A single tree that predicts outcomes using decision rules based on input features.

Random Forest

An ensemble of decision trees that combines multiple predictions to improve generalization.
